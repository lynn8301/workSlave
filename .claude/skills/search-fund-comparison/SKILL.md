## 逐步驟對比

### Step 1：基金績效排名抓取

**原版：**
```
1. 聯網搜尋台股最新「科技型/高科技共同基金」的績效或規模排行
2. 找出前 3-5 名的基金名稱與當前核心特色
3. 找出這幾檔頂尖基金近期高度重疊的 3 檔核心科技股
```

**升級版新增：**
✅ 搜尋來源優先級明確（證交所 > 鉅亨網 > Yahoo）
✅ 篩選目標從「3 檔」擴大到「15-20 檔」
✅ 加入「被基金重疊持有的數量」排序邏輯
✅ **新增分層篩選策略**：
   - 第一層：多檔基金重疊持股（5-7 檔）
   - 第二層：單檔基金重倉持股（4-5 檔）
   - 第三層：基金新進持股（3-4 檔）
   - 第四層：科技產業熱點（補充至 15-20 檔）
✅ **強制時間戳記規範**：
   - 每檔股票標註「幾月幾日收盤」
   - 每檔基金標註「截止幾月底持股揭露」
   - 多數據源差異 > 2% 時主動告警

---

### Step 2：新聞與輿情分析

**原版：**
```
分析外資與投信集體進場這幾檔個股的「底層新聞事件」
判斷該新聞是「剛發酵的潛力題材」還是「利多出盡」
```

**升級版新增：**
✅ 搜尋時間框架明確化：「過去 7 日內」的新聞
✅ 重點新聞類別詳細列舉：美股科技龍頭法說、AI 題材、新訂單、法規利多、併購傳聞、產業景氣、供應鏈移動
✅ **新增時效判斷**：區分「今日新聞」vs「往日延伸效應」
✅ **新增題材生命週期判斷**：區分是「剛發酵」還是「基金已開始套利獲利」
✅ **新增下一個催化劑預判**：評估「短期內 2-4 週是否還有進一步催化劑」（法說、財報季等）

---

### Step 3：護城河評估

**原版：**
```
分析五大指標並打分（1-10 分）
```

**升級版新增：**
✅ 對科技產業的風險評估更深化：「特別針對科技產業的快速變化進行風險評估」
✅ 明確指出科技股的特殊護城河維度：
   - AI、晶片設計軟體的轉換成本特別高
   - 晶片生態的網路效應特別強
   - 高階製程、軟體演算法的技術壁壘特別深
✅ 與同業對比時，對標國際巨頭（NVIDIA、AMD、ASML 等）

### Step 4：財務估值分析

**原版：**
```

```

**升級版新增：**
✅ **科技產業特殊處理**：
   - 本益比對比時加入「科技產業平均本益比」對標
   - DCF 計算時強調「CAGR 假設必須有依據」（高成長率不能憑空）
   - 加入「PEG 比」作為高成長股估值工具
✅ **國際估值對標**：「對標國際同業的估值」（如 NVIDIA 本益比等）
✅ **估值風險警示**：「尤其要警惕科技股的估值泡沫」

### Step 5：操作策略

**原版：**
```

```

**升級版新增：**
✅ **進場點依據更詳細**：
   - 技術面：加入「突破頸線位置」

✅ **停損條件更詳細**：
   - 加入「基金大幅減持」的監控

✅ **停損比例調整**：允許 5-8%（因為科技股波動大）

## 🎯 為什麼這樣升級

### 問題 1：原版只能抓 3 檔股票
❌ 原因：「找出這幾檔頂尖基金近期高度重疊的 3 檔核心科技股」（硬限制）
✅ 解決：新增「分層篩選策略」，確保產出 15-20 檔

### 問題 2：原版沒有時效保證
❌ 原因：無時間戳記規範
✅ 解決：強制每筆數據標註「截止日期」，基金持股標註「月末公告日」

### 問題 3：原版難以分享給朋友
❌ 原因：只有一張表格，語氣專業，不適合非專家分享
✅ 解決：提供三個版本（專業版、簡版、聊天版），都可直接複製

### 問題 4：原版沒有科技股特殊考量
❌ 原因：泛用框架，沒有針對科技產業的特殊風險
✅ 解決：在護城河、估值、風控各環節都加入「科技股特殊處理」

### 問題 5：原版基金來源不明確
❌ 原因：籠統說「前 3-5 名的基金」，用戶不知道具體是哪些基金
✅ 解決：明確要求「列出基金名稱與最新績效」，並在決策表上標註「股票被哪些基金持有」
